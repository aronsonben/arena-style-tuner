# Are.na Style Synthesizer

Side project exploring LLM image generation & fine-tuning using [are.na](https://are.na) channels.

By [Concourse Codes](https://concourse.codes).

## Roadmap

Some of the ideas I'd like to implement in the future:

- Save previous generations instead of losing them immediately
- Show sample gens on the home page
- Offer random are.na channel samples instead of hardcoded set
- Pick & choose image gen models
- Directly save gens to an are.na channel of their own?
- Better user & community features to share ideas
- Gen Credits. Not even necessarily to make money some ppl may just not want to go figure out how to get an API key themselves.
